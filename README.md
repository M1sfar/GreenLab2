# GreenLab 2: Инженерная приёмка контроллера теплицы

Практическая работа по обеспечению качества функционирования компьютерных систем (МИП-3/4).

* **Исполнитель:** Кириллова СИ, группа 24-03ИСиП
* **Спецификация:** GreenLab 2.0 (с анализом перехода на версию 2.1)
* **Итоговое приёмочное решение:** Принять учебную сборку (`candidate-fixed.js`) с ограничениями

## Выявленные и исправленные дефекты

1. **BUG-01 (`R05`, граница гистерезиса полива):** насос ошибочно включался на точной границе `humidity = 35` (`humidity <= 35` вместо строгого `humidity < 35`).
2. **BUG-02 (`R03`, память аварийного состояния):** авария `fault` самопроизвольно сбрасывалась на свежем валидном снимке без команды `reset = true` из-за лишней проверки `&& input.age > 30` в функции `hold`.
3. **BUG-03 (`R09`, приоритет распределения бюджета):** при одновременном запросе обоих устройств и `budget = 3` включался насос вместо более приоритетной вентиляции из-за обратного порядка обхода `['pump', 'vent']`.
